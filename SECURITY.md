# Security Policy

## Supported Versions

Security fixes are applied to the latest minor release on the `main` branch.

## Reporting a Vulnerability

If you discover a security vulnerability (for example, path traversal in ZIP extraction or file resolution, command injection, or credential exposure), please **do not** open a public issue.

Instead, report it privately via [GitHub Security Advisories](https://github.com/PramaAditya/ldraw-mpd-mcp/security/advisories/new) or contact the maintainer directly. Please include:

- A description of the issue and its potential impact.
- Minimal reproduction steps or proof-of-concept payload.
- Affected version and environment details.

We aim to acknowledge reports within 72 hours and provide a fix promptly.
